v0.4.0 is here, and HalfEngine has officially entered the third dimension!

<!--more-->

This version focuses on turning abstract data into a visible world, featuring:

* 3D Visualisation of Agents
* A world grid for spatial reference
* An orbit camera system to navigate the simulation
* Basic AI roaming behavior (Agents now move around!)

> **Camera Controls:**
>
> * `LShift+C` to reset
> * `MMB` (mouse wheel press) and drag to orbit
> * `LShift+MMB` and drag to pan
> * Scroll wheel zooms in and out

**What's next?** Now that we can see the world, it's time to touch it! v0.5.0
will focus on interaction, including agent selection, a property inspector, and
configuration file support.
