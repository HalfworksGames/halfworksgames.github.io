Since the release of v0.1.0, work has been ongoing on v0.2.0, integrating ImGui
into the client and providing us with means to debug and visualize the state of
the simulation without having to sift through walls of text in the console!

<!--more-->

This release introduces a few new features:

* Support for debug UI
* In-memory state serialization
* Support for broadcasting data server-side
* Support for receiving data client-side

**What's next?** The next release will focus on the simulation itself.
Implementing the core simulation loop needed to get the ball rolling. Followed
by introducing the very first AI Agents that will roam this barren virtual
world.
