Work on v0.3.0 has been ongoing and brings a bunch of vital new features,
including:

<!--more-->

* The core, fixed-step simulation loop
* Introduction of Agents into the simulation
* State serialization and replication (the server sends the simulation state to
  connected clients)
* State visualisation in the client. Text-only for now

**What's next?** Next up we are going 3D! v0.4.0 will introduce 3D
visualization of the Agents (as basic shapes. Nothing complex, yet!) and a
basic camera system that enables us to look around the world!
